# Банк задач live-coding — урок 16

Пять задач для самопрогона урока 16 и итогового урока 22. Формулировки —
не код: пишете и проговариваете решение сами, без ИИ-плагинов и
автодополнения. Каждая задача — на паттерн, который курс уже разобрал в
уроках 13–15; новая здесь только формулировка, не приём.

Перед стартом выберите **одну** задачу — ту, чей номер не совпадал с вашим
разбором в теории урока. Остальные оставьте про запас на урок 22.

## 1. Первый неповторяющийся символ

По строке верните индекс первого символа, который не повторяется в этой
строке ни разу. Если такого символа нет — верните -1.

Пример: `"leetcode"` → `0` (буква `l`, единственный раз). `"aabb"` → `-1`.

Паттерн: подсчёт через хеш-таблицу (урок 14).

## 2. Максимум в скользящем окне размера k

По списку чисел и размеру окна `k` верните список максимумов в каждом окне
размера `k`, при движении окна слева направо на один элемент за шаг.

Пример: `nums = [1, 3, -1, -3, 5, 3, 6, 7]`, `k = 3` →
`[3, 3, 5, 5, 6, 7]`.

Паттерн: скользящее окно (урок 14); наивное решение — вложенный цикл
O(n·k), это нормальная отправная точка для разговора о сложности вслух.

## 3. K ближайших точек к началу координат

По списку точек `(x, y)` и числу `k` верните `k` точек, ближайших к
`(0, 0)` по евклидову расстоянию. Порядок точек в ответе не важен.

Пример: `points = [(1, 3), (-2, 2)]`, `k = 1` → `[(-2, 2)]`.

Паттерн: сортировка как подготовительный шаг (урок 15); для больших `k`
стоит обсудить вслух, зачем нужна полная сортировка, а зачем — нет.

## 4. Вставка нового интервала

По отсортированному списку непересекающихся интервалов и новому интервалу
вставьте новый интервал в список, объединив его с пересекающимися.

Пример: `intervals = [(1, 3), (6, 9)]`, `newInterval = (2, 5)` →
`[(1, 5), (6, 9)]`.

Паттерн: слияние интервалов (урок 15), но без предварительной сортировки —
список уже отсортирован, это меняет разговор о сложности.

## 5. Число компонент связности в графе

По списку смежности неориентированного графа верните число компонент
связности (групп вершин, между которыми есть путь).

Пример: граф с рёбрами `0-1`, `1-2`, `3-4` → `2` компоненты (`{0,1,2}` и
`{3,4}`).

Паттерн: обход графа (урок 16), но DFS вместо BFS модуля `Graphs.kt` —
хорошая задача, чтобы вслух объяснить, почему для этой цели подходит и
BFS, и DFS, а для кратчайшего пути — только BFS.

## Формат прогона (напоминание, разбор — в тексте задания урока 16)

Одна задача, 30–45 минут, вслух: уточнение условия до кода → сложность до
кода → решение → проверка граничных случаев → итог. Метка времени у
каждого пункта в расшифровке.

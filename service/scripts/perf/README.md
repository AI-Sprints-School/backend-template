# Большой набор данных для главы 7

`large_dataset.sql` наполняет базу: 20 000 курсов (90 % опубликованы), 200 000
уроков, 20 000 пользователей, ~500 000 отметок прогресса. Время на ноутбуке —
около 10 секунд.

## Замер эталона — 13.09.2026

PostgreSQL 18.6 в Docker, Apple Silicon, схема V1–V3, набор по умолчанию, по два
прогона каждого запроса.

| Запрос | Без индекса | С индексом | План |
|---|---|---|---|
| Каталог: `WHERE is_published AND difficulty = 'beginner' ORDER BY created_at DESC LIMIT 20 OFFSET 5000` | 12,7 / 12,7 мс, `Seq Scan on courses` | 2,3 / 2,4 мс | `Bitmap Index Scan` по частичному индексу `(difficulty, created_at DESC) WHERE is_published` |
| Поиск: `title ILIKE '%урс 1234%'` | 14,9 мс, `Seq Scan` | не меняется | B-tree не помогает подстроке с `%` в начале |
| Прогресс пользователя по `user_id` | 0,3 мс | — | индекс уже есть (`ux_user_progress_user_lesson`, V3) |

На 3 курсах из `db/seed` оба плана — `Seq Scan` за доли миллисекунды: разницы
не видно, поэтому для уроков 30–31 нужен этот набор.

# Дефекты главы 8

В шаблоне папка пустая — так задумано. Снимки сервиса с заложенным дефектом
выдаются отдельно, в главе 8, после сдачи урока 34: снимок — это полная
реализация сервиса, и раньше времени он подсказал бы решения глав 1–7.

Что придёт: `defects/<ID>/` — самостоятельная копия сервиса с одним дефектом и
`BUG_REPORT.md`. Ваш собственный код снимок не меняет.

Порядок работы: прочитать репорт → воспроизвести тестом в снимке (тест
красный) → исправить причину → ваш тест зелёный, `./gradlew test` зелёный.

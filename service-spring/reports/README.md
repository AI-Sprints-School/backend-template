# Отчёты прогона тестов и отчёты уроков

Сюда пишет `./gradlew :service-spring:testReport -Pchapter=N` — файл `tests-0N.txt`.
Отчёт коммитится в pull request: его читают ревьюер и ИИ-проверка. CI перегенерирует
отчёт и сверяет с закоммиченным — править файл руками бесполезно.

Отчёты уроков `lesson-NN.md` пишет студент (не длиннее 2000 знаков).
